# Features

Comprehensive overview of yt-dlp features and capabilities.

## Core Features

### Video Downloading
- **Thousands of sites supported** - 1000+ extractors
- **Multiple quality options** - SD to 8K
- **Format selection** - Video, audio, or both
- **Resume capability** - Continue interrupted downloads
- **Playlist support** - Download entire playlists
- **Channel downloads** - Archive channels
- **Live stream recording** - Capture live broadcasts

### Format Handling
- **Adaptive streaming** - HLS, DASH, F4M, ISM
- **Format merging** - Combine video+audio tracks
- **Quality preferences** - Height, bitrate, codec selection
- **Format filtering** - Complex format selection rules
- **Multiple formats** - Download same video in different qualities

### Authentication
- **Browser cookies** - Import from Chrome, Firefox, etc.
- **Username/password** - Direct login support
- **Two-factor auth** - 2FA support for compatible sites
- **OAuth** - Token-based authentication
- **Netrc** - Credential management

### Subtitles
- **Multiple languages** - Download all available subtitles
- **Auto-generated** - Include auto-generated captions
- **Format conversion** - Convert between SRT, VTT, ASS
- **Embedding** - Embed subs in video file

### Metadata
- **Rich metadata extraction** - Title, description, uploader, date, etc.
- **Thumbnail download** - Get video thumbnails
- **JSON export** - Export metadata to JSON
- **NFO files** - Kodi-compatible metadata
- **Embedding** - Embed metadata in files

### Post-Processing
- **FFmpeg integration** - Video/audio processing
- **Format conversion** - Transcode to different formats
- **Audio extraction** - Extract audio from video
- **Video merging** - Merge video+audio
- **Thumbnail embedding** - Add thumbnails to files
- **Metadata embedding** - Add tags, artist, album, etc.
- **Chapter modification** - Edit chapter markers
- **SponsorBlock** - Remove sponsored segments

### Network Features
- **Proxy support** - HTTP, SOCKS5 proxies
- **Rate limiting** - Control download speed
- **Geo-bypass** - Circumvent geo-restrictions
- **Custom headers** - Set custom HTTP headers
- **Multiple backends** - urllib, requests, curl_cffi
- **Browser impersonation** - Mimic browser requests
- **WebSocket** - WebSocket protocol support

### Output Control
- **Template system** - Flexible filename templating
- **Directory organization** - Organize by uploader, date, etc.
- **Archive management** - Skip downloaded videos
- **Batch downloads** - Download from URL lists
- **Playlist ranges** - Download specific playlist items

### Advanced Features
- **Plugin system** - Extend with custom plugins
- **External downloaders** - aria2c, wget, curl integration
- **Concurrent downloads** - Multiple fragments at once
- **Fragment retry** - Robust fragment handling
- **Self-update** - Update yt-dlp automatically
- **Config files** - Save default options
- **Shell completion** - Bash, zsh, fish completion

See individual documentation for details on each feature.
